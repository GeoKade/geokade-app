Buyers often ask whether they need GeoKade Cloud or Enterprise. The honest answer: it depends on **control, data residency, identity, and integration** — not on a longer feature checklist.

## Choose Cloud when

- you want to start quickly with Dutch open data and hosted workspaces
- collaboration and map sharing matter more than private infrastructure
- you are exploring value before a formal procurement cycle

## Choose Enterprise when

- data must stay in your environment
- you need IAM, roles, auditability, and private connectors
- you already run GIS and data platforms that GeoKade should sit beside — not replace

Enterprise is not “more buttons”. It is **governance at organisational scale**.
